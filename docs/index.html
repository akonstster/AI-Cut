Plan, generate, and edit video in one desktop studio.

AI-Cut brings a multitrack editor, storyboard, 3D previs and node-based workflows together on Windows. The editor is free and open source under the MIT license.

What you can do

Edit on a multitrack timeline

Trim and arrange video and audio, add transitions, text, shapes and masks, animate with keyframes and Bézier graphs, and grade color with scopes.

Plan shots and reusable references

Reorder shots and edit durations, prompts and titles. Attach a first frame, a 3D scene, or a previs render. Save characters, places and props as project elements and reference them with @name.

Build workflows visually

Connect prompts, media and generation nodes, reuse templates and import or export graphs. Model-specific ports, field help and launch checks explain missing inputs and reference limits. Takes help compare alternatives.

Block a scene locally

Place stand-in characters, plan camera positions and movement, and render reference frames or clips locally. Use previs to guide composition and motion before spending on generation.

Generate with your own keys

Use OpenRouter, fal or Runware for image, video, music, speech, sound, lip sync and text tasks where supported. Review model capabilities, estimated costs and recorded spending.

Find and preview media

Analyze photos and frames, search by meaning across languages, refine the top results, and use visual and palette signals. Double-click a photo or video to open a large preview.

Use local AI tools

Generate subtitles with Parakeet or Whisper, synthesize speech with Kokoro or Supertonic, make music with MusicGen and interpolate frames with RIFE. Manage model downloads in Settings.

Finish and deliver

Render HTML graphics with Motifs, export video and FCPXML, normalize loudness, and export subtitles as SRT, VTT, TXT or JSON. Use word-by-word and karaoke captions.

Connect an agent through MCP

Control the editor and timeline, work with storyboard, workflows, elements and 3D previs, and inspect or submit generation jobs. The editor shows the local endpoint and connection command.

What AI-Cut changes

Foundation from VideoSOS 2.1

Storyboard, the node canvas, Takes, Motifs and 3D previs are adapted from upstream work. AI-Cut builds on these tools with the connections and project behavior below.

Storyboard, Workflow and previs stay connected

Linked prompts stay in sync. From a shot, jump to its related workflow cards. Shot durations recalculate the positions of later shots, and first frames and previs are saved as shot references.

Creative state travels with the project

Storyboard, Workflow, elements, previs, Motifs and generation drafts follow the project. Duplicate or export and reimport a project with media references remapped. Imported generation history is available as archival records.

More precise multilingual scene search

Multilingual E5 matches queries against descriptions, CLIP adds a visual signal, and a local BGE reranker refines the strongest matches. Existing captions can be indexed without analyzing the media again.

Clearer generation and media controls

Inspect model-specific inputs and options, see why a node cannot run, receive reference-limit warnings, and reuse existing project media without duplicating it. Copy file names and paths and preview media at full size.

Independent Windows distribution

AI-Cut ships its own installer and portable package, with separate app data, a configurable local MCP port, and no upstream Studio Hub telemetry or updater. The public issue tracker accepts feedback through GitHub.
